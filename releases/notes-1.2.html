Sono 1.2

You can finally see the local model download.

A download you can watch

  • Choosing the local model now shows a real percentage and byte count, "46% · 963.7 MB of 2.05 GB", and a bar that moves with it.
  • Previously it showed 0% for the entire download, then in 1.1.1 a bar too thin to see move. It was working both times, but there was no way to know that, and twenty minutes of a frozen number looks exactly like a hang.
  • The model now comes from Sono's own release page rather than a third party, which in testing was about three times faster and, more importantly, means the total is known before the first byte arrives. That is where the honest percentage comes from.
  • The download is checked against a pinned SHA-256 before it is unpacked, so a corrupted or interrupted transfer is caught rather than half installed.

Also fixed

  • Switches follow your accent colour again on macOS 26.0. They were drawn in the system blue there and ignored the theme, while behaving correctly on 26.5. Sono now draws its own switch, so it looks the same on every version.
  • Remove all data now deletes the local model too.

Nothing about how the enhancement works has changed, only how the model gets here. If you already have it downloaded, this update leaves it alone.
