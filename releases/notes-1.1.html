Sono 1.1

Enhancement without Apple Intelligence.

A second way to clean up your words

  • Enhancement can now run on a local model instead of Apple Intelligence. It works on any Apple Silicon Mac, including the ones Apple Intelligence does not support and the regions where it is not offered.
  • It is Qwen3 4B, and like everything else in Sono it runs here. Nothing is uploaded either way.
  • Its context window is 32,768 tokens against Apple Intelligence's 4,096, so a long dictation is no longer cut short.
  • The model is a one time 2.3 GB download and only happens if you choose it. Settings tells you before it starts.

Choosing between them

  • Off stays the default and is instant.
  • Apple Intelligence adds about a second.
  • The local model adds 2 to 2.5 seconds and is the more thorough of the two on lists and self-corrections.

Settings now shows all three side by side with what each one costs you, rather than a switch that only said on or off.

Also in this release

  • Remove all data now deletes the local model too. It removes only Sono's own model, never the shared cache other tools use.
  • Fixed the version Sono reported about itself. It said 0.1 while calling itself 1.0, which would have made this update offer itself repeatedly.

Your existing setting is untouched. If Enhancement was on it is still on Apple Intelligence, and if it was off it stays off. Requires macOS 26 or later.
