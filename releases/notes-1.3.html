Sono 1.3

Sono can start itself now.

  • Open at login. A new Startup setting registers Sono as a login item, so it is running and listening for your hotkey as soon as you sign in. It uses the system's own login item list, which means turning it off in System Settings turns it off in Sono too.
  • If macOS refuses the registration, usually because Sono is being run from the disk image rather than the Applications folder, the setting now says so instead of quietly switching itself back off.

Open at login was contributed by Sarvesh Patil, the first outside contribution to Sono. Thank you.
